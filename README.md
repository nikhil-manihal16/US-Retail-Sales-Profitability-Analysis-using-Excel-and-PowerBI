# US Retail Sales Profitability Analysis using Excel and PowerBI
Data Analysis project using Excel and Power BI to clean, analyze, visualize, and extract business insights from sales data.

# 📌 Project Overview
This project analyzes **10,000 US retail sales orders** recorded from **January 2024 to December 2025** to uncover meaningful business insights and identify key trends in sales, profitability, customers, products, regions, returns, and payment methods.

# 🎯Business Objectives
The main objective of this project is to understand overall business performance and answer key questions related to:
* 💰 Sales performance
* 📈 Profitability
* 👥 Customer behavior
* 📦 Product performance
* 🌎 Regional performance
* 🔄 Return patterns
* 💳 Payment-method trends
